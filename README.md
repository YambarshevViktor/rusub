Subtitles translated and formatted by people, not by machines. No registration, no ads — free.

- Человеческий перевод и оформление, совместимое с любым плеером<br>Human translation and formatting that works in any player
- Форматы: `.srt` для фильмов, `.zip` для серий<br>Formats: `.srt` for movies, `.zip` for series
- Поиск и фильтры по названию и переводчику<br>Search and filters by title and translator
- Кнопка **Video** — подсказывает, где искать исходник на трекерах<br>The **Video** button — hints where to find the source on trackers
- Рейтинги IMDb / Letterboxd / Rotten Tomatoes / Metacritic<br>Ratings: IMDb / Letterboxd / Rotten Tomatoes / Metacritic
