Субтитры, которые перевели и оформили люди, а не нейросети. Без регистрации и рекламы, бесплатно.

- Человеческий перевод и оформление, совместимое с любым плеером
- Форматы: `.srt` для фильмов, `.zip` для серий
- Поиск и фильтры по названию и переводчику
- Кнопка **Video** — подсказывает, где искать исходник на трекерах
- Рейтинги IMDb / Letterboxd / Rotten Tomatoes / Metacritic

## Технологии

Vanilla JS, без сборки и зависимостей. Статика на Cloudflare Pages.
