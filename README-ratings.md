# Автообновление рейтингов (IMDb / Rotten Tomatoes / Metacritic)

Раз в сутки (и по кнопке вручную) GitHub сам заходит на OMDb, берёт оценки
по каждому фильму и записывает их в `ratings.json`. Сайт при загрузке
читает этот файл и подставляет оценки поверх того, что вписано руками в
`FILMS` — то есть ручные значения работают как запасной вариант, пока
автоматика ещё не нашла оценку (или для площадок, которых у OMDb нет).

Letterboxd автоматика не трогает вообще — у OMDb его нет, вписывайте как раньше.

**Писать нужно только в одно место — `FILMS` в `script.js`, как и раньше.**
Список для OMDb (id/title/year) Action сам вытаскивает прямо оттуда при
каждом запуске, отдельный файл вести не нужно.

## Как включить (один раз)

1. **Файлы уже на нужных местах** — распакуйте архив прямо в корень
   репозитория (там же, где `index.html`):
   - `ratings.json` — сюда автоматика будет писать результат (сейчас `{}`)
   - `scripts/update-ratings.mjs` — сам скрипт
   - `.github/workflows/update-ratings.yml` — расписание для GitHub

2. **Добавьте секрет с ключом OMDb.** В репозитории на GitHub:
   `Settings → Secrets and variables → Actions → New repository secret`
   - Name: `OMDB_API_KEY`
   - Value: ваш ключ (тот, что пришёл на почту с omdbapi.com)

3. **Запустите один раз вручную**, чтобы сразу заполнить `ratings.json`,
   не дожидаясь ночи: вкладка **Actions** на GitHub → слева "Update ratings"
   → кнопка **Run workflow** справа.

4. Дальше он сам, каждый день в 06:00 UTC — коммитит обновлённый
   `ratings.json`, если что-то изменилось.

## Как добавлять новые фильмы дальше

Как обычно — один объект в `FILMS` (`script.js`), не забывая про `id`.
Больше ничего дописывать не нужно: при следующем запуске Action сам
подтянет id/title/year из этого же объекта и найдёт его оценки.

## Если у фильма OMDb ничего не находит

Часто бывает с маленькими/фестивальными/совсем новыми тайтлами — тогда
просто ничего не запишется в `ratings.json` для этого id, и на карточке
останется то, что вписано руками в `ratings` внутри `FILMS`. Ничего
чинить не нужно, это штатное поведение.

## Полезно знать

- 1 запрос OMDb = 1 фильм = сразу все три оценки (imdb+rt+metacritic) в
  одном ответе. Бесплатный тариф — 1000 запросов/день, при вашем
  размере каталога это огромный запас даже если гонять хоть каждый час.
- Если Action не запустился сам по расписанию — GitHub иногда отключает
  cron у неактивных репозиториев после ~60 дней без коммитов; в этом
  случае просто запустите вручную (шаг 3) — расписание снова оживёт.
