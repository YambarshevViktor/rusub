Subtitles translated and formatted by people, not by machines. No registration, no ads — free.

- Human translation and formatting that works in any player
- Formats: `.srt` for movies, `.zip` for series
- Search and filters by title and translator
- The **Video** button — hints where to find the source on trackers
- Ratings: IMDb / Letterboxd / Rotten Tomatoes / Metacritic

## Tech

Vanilla JS, no build step, no dependencies. Static site on Cloudflare Pages.
