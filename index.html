What is this site?
Rusub is a free catalog of fan-made Russian subtitles.
We collect human-translated and formatted .srt files for movies and series — no registration, no ads.
How do I watch a movie?
1 Download the subtitles from this website 2 Download the movie file from the internet 3 Place the subtitles file in the same folder as the movie 4 Name both files the same way: Film.mkv, Film.srt 5 Open the video — subtitles load automatically 6 If not — enable them in player settings and select the .srt file
